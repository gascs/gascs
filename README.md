#### 🌙 [Mo](https://github.com/gascs/Mo) — 個人博客

> *「 一張白紙，一行代碼，一盞夜燈 」*

Go + React 全棧博客。Markdown 編輯 + 實時預覽、SQLite FTS5 全文搜索、RSS、暗黑主題、Let's Encrypt 自動 HTTPS。一鍵部署。

`Go` `React` `TypeScript` `SQLite` `Tailwind CSS` `Docker`

```bash
./bootstrap.sh       # 一鍵契約
make docker-up       # 次元召喚
make deploy HOST=x   # 遠程転送
```

`Kotlin` `Jetpack Compose` `Room` `Hilt` `WorkManager` `Material 3`
